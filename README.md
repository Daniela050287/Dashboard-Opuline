# Dashboard-Opuline
Relatório desenvolvido no Power BI como atividade prática da Alura, com páginas de Vendas e Produtos. Apresenta indicadores de faturamento e quantidade, acompanhamento de metas, evolução das vendas ao longo do tempo e análises por produto, categoria, origem e cidade. Inclui filtros e navegação entre páginas para facilitar a exploração dos dados.
